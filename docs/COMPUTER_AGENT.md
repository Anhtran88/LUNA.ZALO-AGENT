# Windows browser agent
One desktop process; Playwright runs in a single worker thread, UI polls results without blocking. Windows-only headed launch is explicit. No account/site was opened during implementation.

Profiles and encrypted keys are fixed under LOCALAPPDATA/Luna/private, outside repo and OneDrive; configurable output/outbox paths do not redirect sessions. Login/QR/OTP/CAPTCHA are manual. Contexts close on application exit. No cookies/profile export, trace dumps or signed attachment URLs in records/logs.

Zalo: manual group navigation, exact allowlist and single DOM match, exact header plus explicit conversation ID binding, or selected .conv-item row with a stable ancestor data-id, required. Group/file snapshots are invalidated on re-read; identity is checked before and after download. Missing or changed DOM fails closed. Production selectors are not verified: navigation #conversationList .conv-item-title__name, header #header .header-title, pane #messageView and .text-message. Newer layout may use .msg-item[data-id] with a selected .conv-item instead of data-conversation-id. Header/hidden labels outside the list are excluded from duplicate counts. A site build lacking markers is unsupported until authorized DOM inspection establishes a safe mapping. Virtualized lists cannot establish global name uniqueness. No fuzzy matches or whole-page fallback, no scrolling or full-history/date claims.

Files: explicit selected a[download] image/PDF attachments only, approved HTTPS download hosts, signature and 25 MiB checks; browser click/download then local save/hash/metadata. No message sending, upload, editing or UI menus. Temporary browser downloads stay under private local AppData. File size is checked after download; failed validation may leave a temporary browser artifact until context cleanup. OneDrive client owns cloud sync.

eOffice: manual login, approved workflow URL, reject visible password form, read only one unambiguous HTML table. Count loaded rows, not all pages. Custom grids/iframe/multiple tables unsupported. Edit preview remains fixture-only and cannot execute. Manual user actions in browser are outside automation; app does not click submit/save.

All cloud/Firebase/model integrations remain inactive; mock flows remain available. Graceful shutdown waits for the queued browser action before closing context; a stalled download may require closing the browser manually.

Read outcome now distinguishes ready/files_only/content_not_loaded/unsupported_layout. A missing text selector never bypasses attachment scanning. Empty snapshots cannot become reports. Structural diagnostics are user-triggered and expose only counts, character length and bounded alphabetic CSS class frequencies, not content/HTML/URLs/session/IDs. Login, group identity and extractable content are distinct states. No automatic history synchronization or whole-page fallback.
